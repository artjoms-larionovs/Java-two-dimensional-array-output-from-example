# Java-two-dimensional-array-output-from-example
A program that creates a two-dimensional array with 10 rows and 10 columns. Enter an integer. If the number is equal to 1, then using
nested loops, fill the array according to Option A; but if the number is equal to 2, then fill the array as shown
in Option B, and then display the array on the screen in the form of a table. If the number is neither 1 nor 2, display an
error message. Display the elements of the array on the screen in tabular form, separated by tab characters.
